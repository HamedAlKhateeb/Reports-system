# نظام إدارة تقارير المراجعة وتتبع المشاكل
# Review Reports & Issue Tracker Web Application

تطبيق ويب متكامل مصمم للفرق التقنية ولجان مراجعة الجودة والتعريب، لكتابة وتوثيق تقارير المراجعة (أخطاء البرمجيات + تدقيق جودة الترجمة وفق معايير MQM)، مع محرر نصوص غني يدعم الصور والترقيم التلقائي والتعليقات الحرة، ونظام تصدير ثلاثي (Markdown, DOCX, PDF)، ولوحة متابعة كانبان تفاعلية للمشاكل.

---

## 🌟 أبرز الميزات والمواصفات

1. **نظام ثنائي اللغة بالكامل (Bilingual Arabic RTL / English LTR):**
   - قاموس مركزي موحد `lib/i18n/dictionary.ts` هو المصدر الوحيد لكافة النصوص والمسميات في الواجهة والمحرر ولوحة المتابعة ومحركات التصدير.
   - تبديل فوري للغة الواجهة من صفحة الإعدادات أو شريط التنقل مع تعديل اتجاه المستند (`dir="rtl" | "ltr"`) واستخدام خصائص CSS المنطقية.
   - استقلالية لغة محتوى التقرير عن لغة الواجهة؛ حيث يمكن تحرير وتصدير التقرير بلغته المحددة بغض النظر عن لغة واجهة المستخدم الحالية.

2. **الأمان والمصادقة الصارمة (Firebase Auth + Whitelist):**
   - تسجيل دخول بالبريد وكلمة المرور بالإضافة إلى تسجيل الدخول بحساب Google.
   - منع التسجيل العام المفتوح (No self-signup)؛ حيث يتم فحص القائمة المعتمدة (Authorized Whitelist) ورفض أي حساب غير معتمد حتى وإن نجحت مصادقة Google.
   - حماية كاملة لكافة مسارات التطبيق (`/reports`, `/dashboard`, `/settings`) عبر Next.js Middleware.
   - قواعد أمان Firestore و Firebase Storage على مستوى السيرفر لمنع أي وصول غير مصرح.

3. **محرر تقارير متقدم (TipTap ProseMirror Editor):**
   - محرر بلوكات بأسلوب عصري يدعم العناوين والفقرات والجداول وقوائم التنسيق.
   - حفظ تلقائي دوري (Autosave Debounced ~2s) مباشرة في Firestore.
   - قوالب جاهزة بنقرة واحدة:
     - تقرير أخطاء البرمجيات (Software Defects Report).
     - تقرير تدقيق جودة الترجمة بمقاييس MQM وجداول المؤشرات.
     - تقرير المراجعة الشامل.
     - تقرير فارغ.

4. **عنصر الصور المخصص (Custom Report Image Node):**
   - عند لصق أو إفلات أي صورة في المحرر، تُرفع تلقائياً لـ Firebase Storage.
   - توليد رقم تسلسلي تصاعدي ثابت داخلياً (`صورة-1.png` / `image-1.png`) لا يمكن للمستخدم التلاعب به.
   - حقل نصي فوري قابل للتعديل بالكامل (`caption`) أسفل الصورة منفصل تماماً عن المرجع الداخلي.

5. **محركات التصدير الثلاثية المتطابقة:**
   - **Markdown (.md):** تحويل محتوى التقرير إلى صيغة Markdown نقية مع إشارات للصور بصيغة `![caption](./screenshots/صورة-N.png)` وتنزيلها داخل حزمة ZIP مدمجة.
   - **Word (.docx):** توليد ملف Word منسق باستخدام مكتبة `docx`، متضمناً جدول بيانات التقرير، رؤوس جداول داكنة بنصوص بيضاء، تلوين خلايا الخطورة (أحمر للحرجة، برتقالي للكبيرة، أصفر للطفيفة)، ملحق الصور، ودعم `bidirectional: true` ومحاذاة اليمين عند كون التقرير بالعربية.
   - **PDF (.pdf):** تحويل ملف الـ DOCX إلى PDF عالي الجودة عبر LibreOffice Headless داخل حاوية Docker على Google Cloud Run مع خطوط Noto العربية.

6. **لوحة كانبان لتتبع المشاكل (Kanban Issue Tracker):**
   - أعمدة الحالات (`open` مفتوحة، `in_progress` قيد التنفيذ، `done` مكتملة).
   - سحب وإفلات البطاقات بسلاسة (Drag and Drop) وتحديث الحالة فورياً دون إعادة تحميل الصفحة.
   - تلوين البطاقات حسب الخطورة (`critical`, `major`, `minor`).
   - سجل تعليقات زمني لكل مشكلة وإمكانية ربط المشكلة بتقرير مراجعة محدد مع منع حذف التقرير طالما توجد مشاكل مرتبطة به.

## 🛠️ متطلبات التشغيل والتثبيت المحلي

```bash
# 1. تثبيت الحزم
npm install

# 2. إنشاء ملف الإعدادات المحلية
cp .env.example .env.local

# 3. تشغيل خادم التطوير
npm run dev
```

التطبيق سيعمل مباشرة على: `http://localhost:3000`

> **ملاحظة الوضع التجريبي (Demo Mode):**
> إذا لم تقم بإدخال مفاتيح Firebase بعد، سيعمل التطبيق تلقائياً في الوضع التجريبي الكامل (Demo Mode) باستخدام بيانات تجريبية وقائمة معتمدة افتراضية (`reviewer@example.com` أو `admin@example.com`) دون أن ينهار، لتتمكن من تجربة وفحص كافة الشاشات والمحرر والتصدير محلياً!

## 🚀 النشر على Google Cloud Run

تم إعداد ملف `Dockerfile` متعدد المراحل مخصص لـ Cloud Run، ومثبت به محرك LibreOffice مع حزم الخطوط العربية والدولية الكاملة:

```bash
# بناء الصورة محلياً أو عبر Cloud Build
gcloud builds submit --tag gcr.io/[PROJECT-ID]/review-reports-app

# النشر على Cloud Run
gcloud run deploy review-reports-app \
  --image gcr.io/[PROJECT-ID]/review-reports-app \
  --platform managed \
  --region europe-west1 \
  --allow-unauthenticated \
  --memory 2Gi \
  --cpu 2
```

## 🔒 قواعد الأمان (Firebase Security Rules)

- `firestore.rules`: تفرض التحقق من `request.auth != null` على جميع المجموعات (`reports`, `images`, `issues`, `comments`, `counters`).
- `storage.rules`: تمنع رفع أو قراءة لقطات الشاشة من غير المستخدمين المصادق عليهم.
