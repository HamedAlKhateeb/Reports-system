# 📊 نظام إدارة تقارير المراجعة وتتبع المشاكل
# Review Reports & Issue Tracker Web Application

> **تطبيق ويب متكامل مصمم للفرق التقنية ولجان مراجعة الجودة والتعريب**، لكتابة وتوثيق تقارير المراجعة (أخطاء البرمجيات + تدقيق جودة الترجمة وفق معايير MQM العالمية)، مع محرر نصوص غني يدعم الجداول الديناميكية والتحكم الكامل بالصفوف والأعمدة، والترقيم التلقائي للصور، ومساعد ذكاء اصطناعي متخصص (Gemini AI)، ونظام تصدير ثلاثي (Markdown ZIP, DOCX, PDF)، ولوحة كانبان تفاعلية، ودعم كامل للوضعين الداكن والفاتح مع جمالية التحرير الدافئة (Warm Minimalist Editorial).

## 🌟 أبرز المزايا والمواصفات (Key Features)

1. **نظام ثنائي اللغة بالكامل (Bilingual Arabic RTL / English LTR):**
   - قاموس مركزي موحد (`lib/i18n/dictionary.ts`) هو المصدر الوحيد لكافة المصطلحات وعناوين الجداول ومستويات الخطورة وحالات المشاكل.
   - تبديل فوري بين العربية (RTL) والإنجليزية (LTR) من الإعدادات أو شريط التنقل.
   - استقلالية تامة بين لغة الواجهة ولغة التقرير المحرر؛ يمكنك تحرير تقرير إنجليزي في واجهة عربية والعكس بكل سلاسة.

2. **مصادقة محكمة مع وضع تجريبي (Firebase Auth + Whitelist + Guest Mode):**
   - تسجيل دخول عبر البريد الإلكتروني وكلمة المرور أو عبر حساب Google.
   - حماية المسارات عبر `middleware.ts` مع فحص القائمة البيضاء للمستخدمين المصرح لهم.
   - زر الدخول كضيف (**Continue as Guest**) لتجربة واختبار النظام فوراً بدون الحاجة لإنشاء حساب أو إعدادات مسبقة.

## 🧩 التحكم الديناميكي بالجداول (Dynamic Tables)

يوفر المحرر تحكماً ديناميكياً شاملاً بالجداول عبر شريط أدوات سياقي يظهر تلقائياً بمجرد الوقوف داخل أي جدول:

- **إدراج الجداول:** إنشاء جداول بأبعاد مخصصة بضغطة زر واحدة.
- **تحكم الصفوف (Rows):**
  - إضافة صف لأعلى (`Add Row Above`)
  - إضافة صف لأسفل (`Add Row Below`)
  - حذف الصف الحالي (`Delete Row`)
- **تحكم الأعمدة (Columns):**
  - إضافة عمود قبله لليمين/اليسار وفق الاتجاه (`Add Column Before`)
  - إضافة عمود بعده (`Add Column After`)
  - حذف العمود الحالي (`Delete Column`)
- **دمج وتقسيم الخلايا (Merge & Split):**
  - دمج الخلايا المحددة (`Merge Cells`)
  - فك دمج وتقسيم الخلية (`Split Cell`)
- **رؤوس الجداول القابلة للتعديل (Editable Headers):**
  - تحويل الصف الأول إلى صف عناوين برؤوس داكنة (`Toggle Header Row`)
  - تحويل العمود الأول إلى عمود عناوين (`Toggle Header Column`)
  - إمكانية النقر والكتابة المباشرة داخل أي عنوان رأس جدول وتغيير مسمياته بحرية.
- **سحب وتغيير حجم الأعمدة (Column Resizing):**
  - دعم السحب المباشر لحدود الأعمدة لتوسيعها أو تضييقها مع مؤشر بصري واضح (`.column-resize-handle`).
- **حذف الجدول:** زر آمن لحذف الجدول كاملاً.

## 🤖 المساعد الذكي المتخصص (Scoped Gemini AI Assistant)

تم تزويد النظام بمساعد ذكاء اصطناعي محصور بالكامل في مهمة مراجعة التقارير وتدقيق الجودة:

- **معالجة المستندات:** قراءة وتحليل ملفات الـ `PDF` و `DOCX` و `MD` و `TXT`.
- **استخراج الأخطاء والمؤشرات:** استخراج العيوب البرمجية ومؤشرات جودة الترجمة (معيار MQM: الدقة، الطلاقة، المصطلحات، النمط) وتحديد مستويات الخطورة.
- **المحادثة المباشرة:** إمكانية مخاطبة المساعد وسؤاله عن جودة الترجمة وتوصيات التحسين.
- **التنفيذ التلقائي بالسيستم:** إمكانية تحويل مخرجات التحليل مباشرة بنقرة زر إلى **تقرير مراجعة رسمي** أو **مشاكل في لوحة الكانبان**.
- **مفتاح API خاص بالمستخدم (Custom API Key):** يمكن لكل مستخدم إدخال مفتاح Google Gemini API الخاص به من صفحة الإعدادات أو داخل نافذة المساعد مباشرة، مع حفظه بأمان في المتصفح (`localStorage`).
- **محرك احتياطي ذكي (Built-in Fallback Engine):** في حال عدم توفر مفتاح، يعمل محرك التحليل الدلالي الداخلي لتقديم نتائج تجريبية فورية.

## 🎨 التصميم والسمات البصرية (Design & Themes)

تم تصميم التطبيق وفق فلسفة **Editorial Warm Minimalism**:
- **الألوان:** خلفية بيضاء دافئة هادئة (`#FAFAF8`)، نصوص رئيسية واضحة مريحة للعين (`#202020`)، حدود رقيقة وخفيفة (`#E7E6E2`)، ولون تمييزي هادئ واحد من درجات الزيتوني العميق (`#2E4034` / Deep Olive).
- **السمات (Theme Modes):**
  - **الوضع الفاتح (Light Mode):** مظهر مكتبي كلاسيكي دافئ وراقي.
  - **الوضع الداكن (Dark Mode):** واجهة داكنة مريحة للعين ليلاً (`#161615`).
  - **تلقائي (System Default):** يتوافق تلقائياً مع تفضيلات نظام تشغيل المستخدم.
- **الخطوط العربية الراقية:**
  - `IBM Plex Sans Arabic` — خط هندسي رصين لواجهة المستخدم والتقارير.
  - `Noto Sans Arabic` — خط عملي فائق الوضوح للجداول والبيانات.
  - `Amiri` — خط نسخي مائل للاقتباسات والعناوين التحريرية.
  - `Tajawal` & `Readex Pro`.

## 👤 وضع الزائر والطباعة (Guest Mode & Print)

- **الدخول كزائر (Guest Mode):** لتجربة جميع شاشات النظام دون الحاجة لربط Firebase Auth أو امتلاك حساب مصرح.
- **طباعة لوحة التحكم (Print Dashboard):** زر مخصص في لوحة المتابعة يفتح نافذة الطباعة المنظمة مع تنسيقات CSS طباعية خاصة (`@media print`) تخفي القوائم والأزرار وتجهز كشفاً ورقياً للمشاكل وحالاتها ومؤشرات الجودة.

## 📦 محركات التصدير الثلاثية (Triple Export System)

1. **Markdown ZIP (.zip):** ملف `.md` منسق مع مجلد مرفق للصور المرقمة تسلسلياً (`صورة-1.png`).
2. **Word Document (.docx):** وثيقة Word متكاملة بجداول منسقة، رؤوس داكنة، تلوين خلايا الخطورة (أحمر، برتقالي، أصفر)، ودعم كامل للـ RTL.
3. **PDF Document (.pdf):** تصدير عالي الدقة عبر محرك LibreOffice Headless المدمج في حاوية Docker.

## 📋 لوحة متابعة المشاكل (Kanban Issue Tracker)

- تقسيم ثلاثي مرن للحالات: **مفتوحة (Open)**، **قيد التنفيذ (In Progress)**، **مكتملة (Done)**.
- سحب وإفلات تفاعلي سلس (Drag & Drop) مع تحديث فوري للحالة.
- فلترة متقدمة حسب التقرير المرتبط أو مستوى الخطورة.
- سجل زمني للتعليقات والمناقشات حول كل مشكلة.

## 🛠️ التشغيل والتثبيت المحلي (Local Setup)

```bash
# 1. استنساخ المستودع
git clone https://github.com/HamedAlKhateeb/Reports-system.git
cd Reports-system

# 2. تثبيت الحزم البرمجية
npm install

# 3. إعداد متغيرات البيئة
cp .env.example .env.local

# 4. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

## 🌐 النشر والاستضافة (Deployment Options)

> **ملاحظة بخصوص GitHub Pages:**
> منصة GitHub Pages مخصصة للمواقع الساكنة فقط (Static HTML/CSS). وحيث أن هذا التطبيق يعتمد على Next.js App Router و API Routes لتصدير ملفات DOCX و PDF ولمعالجة الذكاء الاصطناعي، يوصى بنشره عبر أحد الخيارات التالية:

### 1. النشر على Vercel (موصى به - مجاني وسريع)
- اربط مستودع GitHub بحسابك على [Vercel](https://vercel.com).
- أضف متغيرات البيئة من `.env.example` في لوحة تحكم المشروع.
- اضغط **Deploy**.

### 2. النشر على Google Cloud Run عبر Docker
يتضمن المستودع ملف `Dockerfile` مجهزاً بمحرك LibreOffice والخطوط العربية:
```bash
gcloud builds submit --tag gcr.io/[PROJECT-ID]/review-reports-app
gcloud run deploy review-reports-app \
  --image gcr.io/[PROJECT-ID]/review-reports-app \
  --platform managed \
  --region europe-west1 \
  --memory 2Gi \
  --cpu 2
```
