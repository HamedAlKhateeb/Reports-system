# 📊 نظام إدارة تقارير المراجعة وتتبع المشاكل
# Review Reports & Issue Tracker

تطبيق ويب متكامل مصمم للفرق التقنية ومراجعي الجودة والتعريب لتوثيق تقارير الأخطاء البرمجية وجودة الترجمة وفق معايير MQM.

---

### ✨ أبرز الميزات
- **ثنائي اللغة بالكامل:** واجهة وتقارير بالعربية (RTL) والإنجليزية (LTR) مع اتساق تام في المصطلحات.
- **محرر متقدم بجداول ديناميكية:** إضافة وحذف الصفوف والأعمدة، دمج الخلايا، وتعديل العناوين مع تغيير حجم الأعمدة بالسحب.
- **مساعد ذكي (Gemini AI):** تحليل مستندات (`PDF`, `DOCX`, `MD`, `TXT`) واستخراج العيوب وتحويلها فوراً لتقارير أو مشاكل، مع دعم إدخال مفتاح الـ API الخاص بك.
- **تصدير ثلاثي:** تصدير كـ Markdown (ZIP)، و Word (DOCX) منسق مع RTL، و PDF.
- **لوحة متابعة كانبان (Kanban):** سحب وإفلات للمشاكل، تصنيف حسب الخطورة، وميزة طباعة اللوحة.
- **تصميم وأوضاع العرض:** وضع داكن وفاتح وتلقائي، بجمالية تحريرية دافئة وخطوط عربية راقية (`IBM Plex`, `Amiri`, `Noto`).
- **تسجيل دخول ووضع الزائر:** مصادقة Firebase مع قائمة معتمدة، بالإضافة إلى زر "الدخول كضيف" للمعاينة الفورية.

---

### 🚀 التشغيل المحلي السريع

```bash
# 1. تثبيت الحزم
npm install

# 2. إعداد المتغيرات
cp .env.example .env.local

# 3. تشغيل المشروع
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

---

### 🌐 الاستضافة وقاعدة البيانات
- **قاعدة البيانات والمصادقة (Firebase):** يستخدم التطبيق Firestore لحفظ التقارير والمشاكل، و Firebase Storage لرفع لقطات الشاشة، و Firebase Auth لحماية الحسابات.
- **الاستضافة السحابية:** نظراً لاعتماد التطبيق على مسارات خادم Next.js (لتصدير الملفات ومعالجة الذكاء الاصطناعي)، يوصى بنشره عبر **Vercel** بضغطة زر مجاناً، أو عبر **Firebase Hosting** / **Docker (Cloud Run)**.
